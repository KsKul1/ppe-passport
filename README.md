# Паспорт ППЭ

Демонстрационный интерфейс системы мониторинга готовности пунктов проведения экзаменов Луганской Народной Республики.

## Возможности

- обзор готовности ППЭ;
- заполнение разделов паспорта;
- работа с замечаниями и сроками;
- календарь и уведомления;
- светлая и тёмная темы;
- адаптивный интерфейс для компьютеров и мобильных устройств.

## Демо-доступ

- Республика: `republic` / `lnr2026`
- ППЭ 6110: `ppe6110` / `ppe2026`

Все данные демонстрационной версии сохраняются только в `localStorage` браузера. Это статический прототип без серверной авторизации и общей базы данных.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в корне проекта.

## Публикация

Workflow `.github/workflows/pages.yml` автоматически публикует сайт в GitHub Pages после push в ветку `main`.
